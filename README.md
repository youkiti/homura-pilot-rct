# HOMURA pilot RCT: pre-registered allocation records

This repository holds time-stamped records for the HOMURA pilot randomized controlled trial
("Human-overseen large language model assistance for systematic review screening and data
extraction (HOMURA pilot): a pilot randomized controlled trial", Nagoya University).

Before recruitment opens, the SHA-256 hashes of the allocation program and of its random seed
are committed here, and the release is archived in Zenodo. The program and the seed themselves
are kept private so that allocation cannot be predicted, and are released here with the
analysis code when the results are published.

本リポジトリは、HOMURA パイロットRCT の割付プログラムと乱数の種の要約値（SHA-256）を、募集の前に記録するためのものです。プログラムと種の中身は、論文の公表時に解析コードとともにここで公開します。
